# sonata-lib

Shared Verilog for the Sonata projects (`sonata_lcd`, `sonata_bramtest`): the 160x128 ST7735 LCD debug console.

| file | what |
|---|---|
| lcd_dbg.v | the console: a title bar and 15 lines of `LABEL XXXXXXXX` (+ PASS / FAIL / RUN), redrawn continuously, SPI mode 0 at clk/2 |
| lcd_font.v, lcd_init_rom.v | generated by `gen_lcd.py`; do not edit |
| gen_lcd.py | writes the two files above |
| font8x8_basic.h | 8x8 font, public domain (D. Hepper / IBM VGA), from github.com/dhepper/font8x8 |

The panel's init sequence is lowRISC sonata-system's `vendor/display_drivers/st7735/lcd_st7735_init.h` (the three scripts, run in the driver's order), with MADCTL changed to 0xA8 for the board's orientation here.  Pins are in each project's `top.xdc` (from sonata-system `data/pins_sonata.xdc`).

## HyperRAM

| file | what |
|---|---|
| hyperram.v | LiteX's HyperRAM core (`litex/soc/cores/hyperbus.py`) as one module, `litex_hyperram`: 32-bit word-addressed Wishbone for the memory (consecutive addresses are one linear burst, which the master must end inside the device's 4 us), a 16-bit register port for ID / CR0 / CR1, plain-signal pads (the top level puts IOBUFs on dq and rwds). Generated; do not edit |
| gen_hyperram.py | writes it. Needs LiteX and migen (`PYTHONPATH=<migen>:<litex> python3.12 gen_hyperram.py`) only to regenerate; builds do not. Made from LiteX b91b9c6bb |

Why this core and not Sonata's own (sonata-system `rtl/ip/hyperram`, OpenHBMC): LiteX's is fabric flops and tri-state buffers only -- no ODDR / IDDR / IDELAY / ISERDES, no second clock -- which this flow places without trouble; OpenHBMC is built around those primitives and an MMCM at 200+ MHz.  The HyperRAM clock is the core clock / 4, so it is slow (20 MHz here), and the core runs near 83 MHz in this flow.

Latency: the core and the device must agree, and in **variable** latency (4 clocks, CR0 = 0x8FF7).  In fixed (2x) latency one step is four clock edges and the core and lowRISC's W956 model differ by two, so no setting works; in variable latency every matching pair 3..7 passes.
